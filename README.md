# Aurora Atelier — Gen-Z Luxury Accessories Marketplace

A modern, minimalist, aesthetic fine jewelry and custom accessories e-commerce website built with **HTML5, CSS3, JavaScript (ES6+), and Python standard library with SQLite**.

## ✨ Features

- **Gold + White + Warm Cream Gen-Z Aesthetic**: Minimalist, high-end styling with Playfair/Cormorant serif typography, rounded cards, and smooth micro-animations.
- **Login & Welcome Modal**: Seamless authentication with 1-click demo logins for Luxury Buyers and Atelier Admins.
- **Hero Dashboard**: Headline *"Find the Piece That Feels Like You"*, curated gold and silver sections, trust badges.
- **"Describe What You Want"**: Natural language prompt search with instant live catalog matching and bespoke artisan commission forms.
- **"Upload / Paste Inspiration"**: Upload files, drag and drop, or press `Ctrl + V` anywhere on the page to paste clipboard images directly into the inspiration studio.
- **Curated Catalog & Product Detail**: Multi-angle gallery, metal variants (18K Gold, 925 Silver, 14K Rose Gold), sizes, live stock status, and customer reviews.
- **Cart & Slide-Over Drawer**: Dynamic pricing, voucher discounts (`AURORA10`), and complimentary insured delivery.
- **Multi-Step Checkout**: Contact, delivery address, insured courier, and instant payment methods (UPI QR, Card, Net Banking, COD).
- **Order Confirmation & Email Dispatch**: Animated gold checkmark and authentic in-app HTML confirmation email viewer.
- **Live Order Tracker**: Interactive timeline progress bar (`Order Placed` ➔ `Confirmed` ➔ `Preparing` ➔ `Shipped` ➔ `Delivered`).
- **Admin / Seller Dashboard**: Manage inventory, add new jewelry pieces, review bespoke requests with inspiration photos, and update order statuses in real-time.

## 🚀 Running the Project

Run the Python backend server:

```powershell
python app.py
```

Then visit:
```
http://localhost:5000
```
